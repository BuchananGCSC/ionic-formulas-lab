Writing Ionic Formulas Lab

Background and how this works

An ionic compound forms when a positive ion (cation) combines with a negative ion (anion) to make a neutral compound. An ion forms when an atom gains electrons (negative) or loses electrons (positive). The number of each ion you need depends on the charges. For example, Ba+2 and Cl−1 have different charges, so a neutral compound uses two Cl−1 for every one Ba+2. The formula is BaCl2: positive ion first, then negative ion, with the number of each ion as a subscript.

Some ions contain more than one element. These are polyatomic ions, such as NH4+1 and SO3−2. When more than one polyatomic ion is needed, put it in parentheses and write the subscript outside: (NH4)2SO3.

  1. Read the two ions to combine.
  2. Drag ions from the tray onto the bench (or click an ion to add it, and click it on the bench to remove it). You can use as many as you need.
  3. Use the fewest ions that make the total charge zero.
  4. Build the formula: type each element symbol in a big box and its subscript in the small box beside it. A polyatomic ion has more than one element, so use + element (for NH4, that is N, then H with a subscript of 4). If you need more than one polyatomic ion, tick parentheses and put the count outside. Leave a subscript blank when it would be 1.
  5. Type the compound’s name, then press Check my work.
  6. When a problem shows all green checks, write its ion symbols, formula, and name on your lab sheet. Your answers are recorded on paper, not here.
